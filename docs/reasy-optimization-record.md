## 当前状态

- 静态/CPU/DXC：P0–P5 均有对应验证记录，范围见上表；新增/删除限于已识别的 UserMaterial 和 Texture2D，不能推断任意接口都可编辑。
- 总体测试中的 88 项 skip 是缺少可选本地语料，不计为通过；MCP SDK 缺失时的 skip 也不计为通过。
- 没有 GPU 宿主、捕获回放或真实游戏内验证证据。DXC 成功、结构/反射一致、桌面操作成功均不能替代游戏效果验收。
- P6 的 `emission_multiplier` 仅提供模板定义和布局预检，尚未实现该模板的 Shader 效果写入。渲染状态编辑、通用节点图和 GPU 预览均未完成。
- 测试数字是阶段记录，不应相加；不同阶段的测试集合和可选语料条件不同。

## P6 搁置计划

**目标**：在接口增删之外，让 Workbench 能以受限、可验证的方式改变实际渲染效果。P6 原计划包含效果模板和渲染状态编辑，需作为不同功能分别实现和验收。由于预计投入较大，目前暂停，不继续扩展。

**当前已有**：`emission_multiplier` 的封闭模板合同及布局预检，可声明需要 `MMTR_EmissionStrength`、`MMTR_EmissionMap` 等接口。它不修改 Shader，不会单独改变画面，也不代表模板功能已完成。

**恢复后首个候选：自发光倍率模板**

- 假设：能在明确识别的自发光计算位置加入倍率运算，在倍率为 1 时保持原效果、倍率变化时只影响预期的自发光，同时保留原受光、贴图和透明行为。
- 样本：先选一个具有可定位自发光计算的固定 MMTR/MDF 与其实际关联材质，记录文件身份、相关 Shader/渲染通道和修改前效果；不做全库扫描。
- 实施范围：只处理已证明的 Shader 形态及明确的相关通道；其它计算形态、无法确认的通道或未知数据一律拒绝，不扩展为通用 HLSL/节点编辑器。
- 通过判据：离线重建后接口、绑定、旧字段读取及 Shader 验证通过；倍率 1 的输出路径保留原计算；游戏测试同时检查正常受光、自发光、原贴图和透明表现。
- 停止点：只完成该固定样本和已覆盖形态。若无法可靠定位计算、保持其它输出，或通道覆盖不完整，则停在只读预检并记录原因，不开放写入。

**后续独立方向：渲染状态编辑**

先选单一状态字段和固定样本，确认 packed 位/枚举含义、共享状态对象的所有使用者及运行时缓存/hash 约束；明确整体修改还是复制状态对象。完成离线重解析和游戏对照前不开放状态写入。该方向不得与自发光模板捆绑验收。

通用节点图、任意 Shader 生成、自动覆盖所有 MMTR 和 GPU 材质预览不属于已排定的 P6 首个交付范围，需另行评估。

# 独立变体与轻量工程（P4）

核心与桌面 JSON-lines/MCP 后台入口共用 P3 任务管理器，并提供 schema 版本化工程。共享 master 仍同步全部已知关联材质；独立变体只同步所选材质并产生显式导出候选。桌面表单另行进行实际交互验收，不能由协议测试推断桌面或游戏通过。

## 假设与停止点

同一个 MDF 的两个材质共用原 MMTR，只为一个材质生成独立 MMTR，并同步该材质的参数、贴图和 master，可以隔离其它已知使用者。最小实验是自有可执行 HLSL 的一个参数和一个 NullBlack Texture2D 混合追加。

通过条件：原 Service 的 MMTR/MDF 字节和选择不变，另一个材质的公开结构/值保持，输出重开时 master 与真实输出目录及资源版本一致，布局匹配。失败条件：未选材质改变、源或目标被覆盖、重开不一致。停止点为有界核心候选与显式双文件导出，不扫描游戏目录，不自动安装、切换当前文档或执行工程。

## API 与约束

- prepare_material_variant：只读布局规划，绑定所选材质、源内容与 revision、DXC、动作、引擎 master、MMTR/MDF 目标路径和已有目标内容指纹；列出当前 MDF 全部已知同 master 使用者，并明确 external_users=not_scanned。
- build_material_variant：独立 Service 快照上调用已有批量迁移核心。变体计划只同步所选材质；共享计划仍同步全部关联材质。候选经完整原生接口验证、重解析及未选材质语义比较，失败不改调用方。
- export_material_variant：显式写出完整候选对。先核对源/DXC、载荷身份、所有目标、源文件及硬链接保护，再写入并独立重开。普通写入/重开失败恢复已有目标或移除新文件，恢复失败明确报告。没有跨文件进程崩溃原子性保证。

MMTR 目标必须以完整 MaterialShader/.../name.mmtr.当前数字版本 为资源后缀，MDF 目标以 .mdf2.45 结尾。变体 master 不带版本，不能复用当前 MDF 已使用的 master。输出目录须已存在；覆盖已有目标须显式允许，预览后目标出现或内容改变则重新规划。

Service 在整个操作中保持源文档与编辑，导出结果另行打开。这一选择避免将新布局误用到原共享 master。后台构建完成后核对 P3 的 revision/源路径/内容/选择/DXC，成功状态为 candidate_ready；结果只有报告，完整二进制仅保留在会话候选中。显式 export 再检查输入与目标，成功后释放候选并保留幂等收据；discard/close 也释放候选。最多保留一份候选，未处理时拒绝下一批次。

## 轻量工程

`.mmtrproj.json` 的 schema=1，保存源 MMTR/MDF 路径及 SHA256、所选材质 index/name/master、工具与 DXC 身份、动作顺序/默认值、可选独立输出路径。验证摘要固定为 requires_fresh_validation，game_tested=false；不保存载荷、IR、旧偏移、命令或已执行计划。保存前要求磁盘与当前源一致，未另存编辑不能靠工程恢复。

读取工程只与当前已打开的源和材质对照，不自动加载引用、编译或导出。路径/材质错配拒绝，内容或 DXC 改变返回 changed_inputs；所有情况都要求重新规划与验证。封闭字段、重复 JSON key、schema、动作宽度/有限 float32、绝对路径及2MiB上限均检查。保存使用源/硬链接保护，也不能覆盖 DXC 或变体目标；覆盖已有工程须显式允许。

## 本机验证

2026-10-21，Windows x64，合成结构规划与自有 HLSL 的隔离 DXC 实验：

- 共享/独立范围分别为材质0、1与材质0；独立预览仍列出两个已知使用者。
- 一个8B参数和一个默认 NullBlack 贴图只加入材质0，master 改为独立变体；材质1的完整公开语义和原 Service 字节不变。
- 导出重开核对布局、master、版本路径及 MMTR hash/尾项完整性。
- 错误路径/版本、当前 master 冲突、源硬链接、已有目标、预览后目标变化、源状态变化、候选损坏和 worker 失败均拒绝。
- 第二个文件写入失败时，已有两个目标恢复原字节；新目标均移除。未选材质的不同布局不会阻塞独立变体，但共享操作仍明确拒绝不同布局。

相关测试为 tests/test_material_variant.py、tests/test_material_project.py 与 MCP 契约。适配检查点核心355项：267通过/88项可选语料skip；MCP21项通过。源码与当前冻结 EXE 的真实 SDK stdio 各验证30工具、工程恢复后重新计划、共享两材质/独立一材质、候选不改源不写文件、导出重开及其它材质语义不变、预览后目标冲突拒绝、幂等导出、丢弃和源 revision 变化拒绝。自有两Shader样本的状态调用最大0.0018/0.0017秒，不能推广为大文件耗时。

回归日志在忽略的 output/p4-variant-*、output/p4-project-*，协议脚本及收据在 output/p4-source-mcp、output/p4-frozen-mcp。未执行 GPU 或真实游戏验收，版本保持0.3.0；桌面交互、实际Tauri及便携包验收仍是本阶段下一检查点。

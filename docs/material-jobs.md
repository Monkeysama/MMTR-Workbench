# 后台材质批次（P3）

## 范围

在 P2 最终布局核心上增加会话内后台任务，桌面与 MCP 共享一个任务管理器；支持参数和 Texture2D 的混合追加，不扩大 Shader 地址识别或资源类型范围。仍为0.3.0，不自动导出、安装或发布。会话重启不恢复任务。

桌面入口在“参数与资源”的批量图标；原参数/SRV 新增也打开同一表单。填写名称、float1..4 默认值和纹理路径，纹理选择实际 PS 绘制记录。预览显示最终参数区、贴图数量、全部已知关联材质、参数偏移和待分析 Shader 数；执行后显示当前阶段数量，可取消，成功后刷新 MMTR/MDF 并定位新增成员。Sampler/UAV 不接入自动追加。

## 所有权与提交

- 同步 Service 保持可 deepcopy；RpcSession/WorkbenchSession 拥有文档锁、revision 和 MaterialJobs。
- 快照及最终提交持文档锁，计算在独立候选上执行。任务状态仅访问状态锁，不调用 doc.build/mdf.build。
- 锁顺序为文档→任务；状态/取消不等待文档锁。提交内再次检查取消事件；提交已成功则取消仍返回 succeeded。
- 最终核对源 revision、MMTR/MDF 当前 SHA256、源路径、所选材质、DXC 路径/内容和计划摘要。过期结果丢弃，保留较新编辑。
- 每会话只执行一个修改任务；请求键与规范化请求/计划共同去重。幂等记录最多128项，满后拒绝新任务，不淘汰旧键后重复执行。
- 失败、取消和过期都不写文件、不恢复覆盖用户的新状态。结果不保留候选二进制，Shader 修改报告分页读取。

原生 DXC 串行留在独立子进程。Worker 的 stdout 只返回最终 JSON；阶段/数量通过本任务私有临时文件原子更新。取消/超时关闭 Windows kill-on-close Job Object 并回收管道。冻结入口用内核父进程句柄监视 PyInstaller onefile 启动器，防止外层结束后内层核心继续工作；不是只凭源码 Popen 验收推断冻结行为。

桌面网络重试保留原请求键与动作；核心明确拒绝时解除提交状态，传输失败时允许重试原请求。轮询不重叠；取消后忽略旧轮询响应，卸载清理轮询并请求取消。预览只做结构/布局检查，未知 Shader 寻址仍可能在运行时拒绝。

- 核心342项：254通过，88项因各自可选语料/条件跳过；MCP20项通过；前端20通过/1跳过。原生批次用自有可编译 HLSL，合成坏数据不作为可执行 Shader 证据。

本地证据在忽略目录 output/p3-*，包括 core/mcp/frontend/build日志、source/frozen MCP JSON、onefile回收JSON、桌面预览/完成/定位截图。检查命令为 `python scripts/test_core.py`、`python scripts/test_mcp.py`、`npm run test:frontend`、`npm run build`，冻结/桌面构建为 `npm run core:build` 与 `npx tauri build --no-bundle`。真实协议实验的固定输入和脚本保留在本地证据目录，不携带游戏资产入库。

没有执行 GPU 宿主、捕获回放或真实游戏验证。旧单项 MCP 调用仍是同步长调用，智能体应改用后台入口；一次后台批次仍会串行分析全部相关 Shader，不意味着原生计算瞬时完成。状态阶段不是整体 ETA。下一阶段为 P4 独立变体与可恢复工程，P5 读取报告复用已合并模块，删除能力单独验收。
